ISSB-R
====

A cross-platform "Super Smash Bros. Brawl" fan-game, based on [lufinkey/iSSB](https://github.com/lufinkey/iSSB).

This edition includes HD Ichigo sprites with unchanged frame counts, generated HD menus, modern display scaling fixes, and mapped controller input for menus and gameplay. See [controller notes](tools/modern-input/README.md), [HD menu notes](tools/menu-hd/README.md), and [Ichigo notes](tools/ichigo-hd/README.md). Platform builds and physical-device testing remain outstanding.

This project uses git submodules, so in order to download it, you'll have to clone it recursively:

```bash
git clone --recursive https://github.com/nahalewski/iSSB-R.git
```
